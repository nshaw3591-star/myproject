# AI-Powered Travel Planner & Recommender System

> An intelligent, full-stack travel itinerary and hotel recommendation web application powered by **Google Gemini 2.0 Flash**, **Google Places API (New)**, and **Firebase Firestore**.  
> **Final Year Engineering Project — Group 9**

---

## 🌟 Overview

The **AI Travel Planner** creates personalized, multi-day travel itineraries based on destination, duration, budget, and travel companions. By utilizing Google's Gemini 2.0 Flash Large Language Model combined with real-time imagery from the Google Places API, users can discover hotels, tourist spots, optimal visiting hours, and travel times in seconds.

For full architecture diagrams, data contracts, and component breakdowns, see [TECHNICAL_DOCUMENTATION.md](file:///c:/Users/ROHIT/Downloads/drive-download-20260318T071141Z-3-001-20260330T093902Z-1-001/final_year_project/TECHNICAL_DOCUMENTATION.md).

---

## ✨ Features

- 📍 **Google Places Autocomplete:** Fast and accurate destination search.
- 🤖 **AI-Driven Itinerary Generation:** Multi-day itineraries generated by Gemini 2.0 Flash adhering to strict JSON structures.
- 🏨 **Hotel Recommendations:** Curated hotels based on budget tier (_Cheap_, _Moderate_, _Luxury_) with direct Google Maps integration.
- 📸 **Dynamic Photo Enrichment:** Real-time attraction and hotel photos fetched via Google Places API (New).
- 🔐 **Google OAuth 2.0 Authentication:** Secure, one-click sign-in.
- 💾 **Cloud Firestore Persistence:** Saves generated trips to the user's account for review anytime under "My Trips".
- 📱 **Responsive Design:** Built with React 18, Tailwind CSS v4, Radix UI primitives, and Animate.css.

---

## 🛠️ Tech Stack

- **Frontend:** React 18, Vite 6, Tailwind CSS v4, Radix UI, Sonner, Lucide React
- **Routing:** React Router DOM v7
- **AI Engine:** Google Gemini (`gemini-2.0-flash` via `@google/generative-ai`)
- **Database:** Firebase Cloud Firestore
- **Authentication:** Google OAuth 2.0 (`@react-oauth/google`)
- **APIs:** Google Places API (New) (`searchText` & `media`)

## 🚀 Quick Start

### 1. Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### 2. Installation

```bash
git clone <repository-url>
cd final_year_project
npm install
```

### 3. Environment Variables

Create a `.env.local` file in the project root:

```env
VITE_GOOGLE_GEMINI_AI_API_KEY=your_gemini_api_key
VITE_GOOGLE_AUTH_CLIENT_ID=your_google_oauth_client_id.apps.googleusercontent.com
VITE_GOOGLE_PLACE_API_KEY=your_google_places_api_key
```

### 4. Run Development Server

```bash
npm run dev
```

Open `http://localhost:5173` in your browser.

### 5. Build for Production

```bash
npm run build
```
